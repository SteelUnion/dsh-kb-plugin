# DSH-КБ-plugin · 插件设计局

**КБ** = конструкторское бюро（俄语「设计局」）。

> **学 cordis、学 DSH 的最佳入口。**
>
> **这个插件会大大降低你开发 DSH 插件的难度。**

---

## 为什么值得装

写 DSH 插件，卡住你的从来不是代码，是**认知**：

- DSH 里到底有哪些服务？`sessions` 能干什么、`tools` 怎么注册、`llm` 怎么调？
- 它们互相依赖成什么样？我调的这个服务，是不是还要先有别的？
- 我的插件应该 inject 哪些？漏一个不会报错——**它就是不加载**。
- 挂载点在哪？槽位、事件、命令，各自长什么样？

**翻源码要读几万行，翻文档散在十几个包里。**

**这个插件把答案画出来，让你直接看。**

---

## 它是什么

**14 个球，每个球是一层，球里是这一层的服务点，球之间的线是层与层之间的依赖。**

转它、点它、搜它。**选中一个服务，立刻告诉你它依赖谁、谁依赖它、它有哪些方法、每个方法签名长什么样。**

**—— 这就是 cordis 的骨架。**

---

## 你能学到什么

| 想搞清楚 | 怎么用 |
|---|---|
| **DSH 有哪些服务** | 全景看 14 个球、125 个服务 |
| **这一层负责什么** | 点球，看中英文名 + 一句说明 + 层内全部服务 |
| **这个服务怎么用** | 点服务点，右侧出方法清单（签名 + 白话说明） |
| **它依赖谁 / 谁依赖它** | 依赖区按 `direct` / `inferred` 分组，带计数 |
| **依赖长什么样** | 青蓝线 = 它依赖谁，橙线 = 谁依赖它，跨球画出长线 |
| **插件该 inject 什么** | 「插件链」→ 生成方案 → 直出 `export const inject = [...]` |
| **挂载点在哪** | 生成方案里的官方插件形态 + 逐条边落成什么代码 |

## 已实现

### 三维服务图

- **14 个球**（host 5 层 / client 9 层），**125 个服务**，**59 组层间依赖 / 285 条键**
- **拖动旋转、滚轮缩放、双击退回全景**
- **点球聚焦**：球放大居中，其它球缩成可点小点，700ms 平滑飞过去
- **真透视**：远的球小、暗、被近的盖住（焦距 900）
- **曲线键**：**跨面琥珀色、同面石板灰**，一眼分得开
- **球自带节点纹理**：宏观下每个球里都铺着一层极淡的服务点，不选中也看得见这一层有多少东西
- **分级显示**：宏观只看球名、层号水印和淡纹理；聚焦才把球内服务点和缩写全点亮
- **左下角快捷栏**：14 个球的按钮 + 重置视角

### 选中服务

- **右侧面板**：服务中文说明、方法清单（签名 + 白话）、所属球
- **依赖 / 被依赖**：分组、带计数、每个 chip 可点跳转，超过 4 个给筛选框
- **青线** = 它依赖谁，**橙线** = 谁依赖它，带箭头和端点圆
- **跨球**：依赖线穿过球壁画到别的球里，跑出画布的截到边缘
- **宏观也保留**：退回全景后，选中的服务点仍标黄、球外加一圈光晕、**名字和所属球名（中英）都还在**，依赖线也不消失

### 搜索

- 顶部搜索框，输服务名 / 中文说明，**回车直接定位**到那个服务所在的球

### 插件链

- **右侧面板切「插件链」**，三维图不动，可以对照着看
- **按拓扑分层画成 SVG**：同层并排 = 可并发，层间箭头 = 触发顺序
- **边上 A/O 标记**：A = 必要（必须等到），O = 可选（有就带上、不阻塞）
- **点边选中 → 操作栏切 A/O 或删除**
- **`⇢ 连到…`**：点起点 → 点目标 → 连一条边
- **加节点**：`＋ 后续` / `＋ 前置`，以「三维图里选中的服务」为对象，插入到「链条里选中的节点」前后
- **防重**：相邻已有同一模块时不重复建节点，直接连回它
- **防环**：加边前检查会不会成环
- **生成方案**：导出九节 Markdown —— Mermaid 图、逐条边落成什么代码、节点清单、触发规则、`inject` 清单、官方插件形态、待你决定的事项、不确定的地方

## 独立跑（不开 DSH）

这个插件虽然要挂进 DSH 才能用，但**必须能脱离 DSH 自查** ——
否则出了问题只能靠人在 GUI 里手动点，定位不了。

```bash
node ../dsh-kb-plugin-test/run.mjs          # Host + Client 都跑
node ../dsh-kb-plugin-test/run.mjs client   # 只跑客户端半边
```

客户端半边用 **jsdom + 真 React 挂载 + 真事件派发**，把面板真挂起来、真点、真读画布：

```
46 项断言 / 8 个场景
  首屏       canvas 画出来了、14 个球、两个 Tab
  宏观纹理   球内淡纹理存在且够淡
  点球聚焦   面包屑变化、服务点亮起、缩写名出现
  画布选点   直接在画布上点球内节点，能选中
  依赖线     青色和橙色按方向分开
  退回宏观   选中点 + 名字 + 球名 + 光晕 + 依赖线 + 键线全都还在
  插件链     Tab 切换不炸、按钮可用
  加节点     点「＋ 后续」后 plan 节点数 +1 并落盘
```

**它查的是「点下去会怎么样」，不是「源码里有没有这行字」。**

## 安装

目前只能手工装（desktop profile 的 `dsh plugin` 被 CLI 硬拒）：

1. 把本目录放到任意位置
2. 改 `~/.dsh/profiles/desktop/package.json`：
   ```json
   "dsh": { "profile": { "bundles": [ ..., "dsh-kb-plugin" ] } },
   "dependencies": { ... , "dsh-kb-plugin": "link:<本目录绝对路径>" }
   ```
3. `cd ~/.dsh/profiles/desktop && pnpm install`
4. 重启 DSH
5. 左侧栏会出现「插件设计局」图标

**注意**：三处（`bundles` / `dependencies` / `node_modules`）必须同时对得上，缺一处会启动失败。
